## 🎯 Objetivo

Visualizar la **población de México en 2010** y analizar su **distribución espacial por entidad federativa**, con el fin de:
- comparar magnitudes entre estados,
- identificar concentración poblacional,
- y facilitar la exploración geográfica de los datos a través de un mapa interactivo.
